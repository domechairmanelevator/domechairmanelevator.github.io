# MTProto Обзор

> 48 рабочих MTProxy для Telegram — живой список с проверкой пинга.

[![Сайт](https://img.shields.io/badge/сайт-domechairmanelevator.github.io-469d25)](https://domechairmanelevator.github.io/)
[![Канал](https://img.shields.io/badge/Telegram-@mtprxtg-2aabee)](https://t.me/mtprxtg)

## Что внутри

- `48` проверенных прокси-серверов MTProxy: наши серверы @mtprxtg + отобранные публичные;
- проверка доступности прямо на странице (кнопка «Проверить все»);
- подключение в один клик — Telegram открывается сам;
- сайт устанавливается на телефон как приложение (PWA).

**Открыть список:** [https://domechairmanelevator.github.io/](https://domechairmanelevator.github.io/)

## Подключение вручную

Telegram → Настройки → Данные и память → Прокси → MTProto — или просто нажмите «Подключить» на сайте.
